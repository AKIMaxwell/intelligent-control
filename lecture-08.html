一、实验目的

  1. 理解模糊神经网络的核心思想：将模糊推理的可解释性与神经网络的学习能力相结合，使模糊规则的前件与后件参数能够从数据中自适应调整。
  2. 掌握 ANFIS 的五层网络结构与混合学习算法：前向用最小二乘法估计后件线性参数，反向用梯度下降调整前件非线性参数。

  4. 通过 ANFIS 与 PID 的对比，理解数据驱动控制器的能力边界：训练数据的覆盖范围决定了控制性能的上限。
课前必读

二、实验原理（课前必读）

2.1 为什么需要模糊神经网络

常规模糊控制器的规则和隶属函数依赖专家经验人工设定，对象工况变化时性能可能显著下降；纯神经网络控制器虽能从数据学习，但内部权值缺乏物理可解释性。ANFIS 把 Takagi–Sugeno 模糊推理系统嵌入一个前馈网络拓扑，使模糊系统获得"可训练性"——模糊规则不再完全由人写定，而是由数据驱动地优化。

2.2 ANFIS 的五层结构

以二输入单输出为例。输入 $x$ 和 $y$，每个输入 2 个模糊集，共 4 条一阶 Sugeno 规则：

$$\text{Rule } i:\ \text{If } x \text{ is } A_i \text{ and } y \text{ is } B_i,\ \text{then } f_i = p_i x + q_i y + r_i$$
  • 第 1 层（模糊化层，自适应节点）：计算隶属度。高斯隶属函数：
    $$\mu_{A_i}(x)=\exp\left[-\frac{1}{2}\left(\frac{x-c_i}{\sigma_i}\right)^{2}\right]$$
    $c_i,\sigma_i$ 是前件非线性参数。
  • 第 2 层（规则层，固定节点）：触发强度 $w_i=\mu_{A_i}(x)\cdot\mu_{B_i}(y)$。
  • 第 3 层（归一化层，固定节点）：$\bar{w}_i=w_i/\sum_j w_j$。
  • 第 4 层（后件层，自适应节点）：$O_{4,i}=\bar{w}_i f_i=\bar{w}_i(p_i x+q_i y+r_i)$，$p_i,q_i,r_i$ 是后件线性参数。
  • 第 5 层（输出层，固定节点）：$F=\sum_i O_{4,i}$。

2.3 混合学习算法：本实验的核心

ANFIS 训练不是对整个网络统一做梯度下降，而是利用结构特点将参数分两组交替优化：

  • 前向阶段：固定前件参数（$c_i,\sigma_i$），第 5 层输出是后件参数（$p_i,q_i,r_i$）的线性函数。给定 $N$ 组训练样本，写出线性方程组，用最小二乘法一步求出后件参数，不需迭代。
  • 反向阶段：后件更新后，计算输出误差，从第 5 层反传至第 1 层，用梯度下降调整前件参数，改变隶属函数的形状和位置。

一次"前向最小二乘 + 反向梯度下降"称为一个 epoch。混合策略比纯 BP 收敛更快，因为后件线性子问题被解析地一步求解，梯度下降只需处理非线性的前件参数。

2.4 控制回路中的 ANFIS

本实验中 ANFIS 直接充当控制器。控制回路信号关系：

$$e(k)=r(k)-y(k),\qquad \Delta e(k)=\frac{e(k)-e(k-1)}{T_s}$$

ANFIS 以 $e$ 和 $\Delta e$ 为输入，输出控制量 $u(k)$。训练数据来自 PID 闭环：ANFIS 学习的是"在类似误差状态下，PID 是怎么动作的"。

三、实验对象与任务

3.1 被控对象

二阶振荡加纯滞后模型：

$$G(s)=\frac{20}{8s^{2}+4s+1}\,e^{-0.2s}$$
系统类型直流增益自然频率阻尼比纯滞后
欠阻尼二阶$K=20$$\omega_n\approx0.354$ rad/s$\zeta\approx0.707$$0.2$ s（$=2$ 拍，$T_s=0.1$ s）

相比一阶温度对象，该对象是欠阻尼二阶系统，阶跃响应本身就有振荡倾向，对控制器设计更具挑战性。

状态空间实现（脚本采用）
$$A=\begin{bmatrix}0 & 1\\ -0.125 & -0.5\end{bmatrix},\quad B=\begin{bmatrix}0\\ 2.5\end{bmatrix},\quad C=\begin{bmatrix}1 & 0\end{bmatrix},\quad D=0$$

推导要点：由 $G(s)$ 交叉相乘得 $(8s^{2}+4s+1)Y=20U$，归一化后 $y''=-0.125\,y-0.5\,y'+2.5\,u$，取 $x_1=y,\ x_2=y'$ 即得上述矩阵。可自行用 tf2ss(20,[8 4 1]) 对比——状态空间实现不唯一。

3.2 仿真参数

  • 采样周期 $T_s=0.1$ s：对象周期约 17.8 s，每周期约 178 点，足够精细；滞后 0.2 s 恰好对应 2 步延迟。
  • 仿真时长 $T_{\text{end}}=100$ s：阶跃响应在 20~30 s 进入稳态，100 s 留足观察余量。
  • 执行器：脚本中 PID 与 ANFIS 输出限幅均被注释，允许负控制量。注意：数据生成器不限幅能覆盖更大范围，但真实执行器必有限幅，分析时应意识到这一点。

四、实验步骤（按代码模块组织）

脚本共七个模块，与以下步骤一一对应。建议课前通读脚本，课上按模块推进，每个模块都留出观察与记录时间。

模块零：整体流水线认知

核心逻辑：② 产生"老师怎么开"的示范数据，④ 让 ANFIS 从数据中学习这个映射，⑤ 把学到的映射放回闭环检验。整条主线的关键是——数据驱动控制器性能的上限，由训练数据的覆盖范围决定。

步骤 1：对象建模与离散化（对应模块一）

A = [0 1; -0.125 -0.5];  B = [0; 2.5];  C = [1 0];  D = 0;
sys = ss(A, B, C, D);
Ts = 0.1;
sysd = c2d(sys, Ts, 'zoh');
Ad = sysd.A; Bd = sysd.B; Cd = sysd.C;

tau = 0.2;
delay_steps = round(tau / Ts);
u_buf = zeros(1, delay_steps + 1);
这段代码在做什么

把连续二阶对象拆成"无延迟部分用状态空间离散化" + "纯滞后用 FIFO 缓冲区模拟"。

关键原理：c2d(...,'zoh') 选零阶保持器，因为控制量在采样周期内由执行器保持，与实际物理过程一致。delay_steps=round(0.2/0.1)=2，u_buf 长度 3；若改 $T_s=0.05$，delay_steps 自动变 4，缓冲区自动适配。

常见错误 ① u_buf 更新顺序写反（先推入再取 u_buf(end)），导致延迟多一步。验证方法：给对象单位阶跃输入，看输出是否在 0.2 s 后才开始变化。
② 忘记 c2d 直接用连续矩阵做离散迭代，导致发散。
想一想如果把纯滞后从 0.2 s 改成 2 s，delay_steps 变 20，这对 PID 整定和 ANFIS 训练数据有什么影响？

步骤 2：PID 基准控制器与训练数据生成（对应模块二）

Kp = 0.8; Ki = 0.05; Kd = 0.5;
e_int = 0; e_prev = 0;
r = ones(1, N);   % 阶跃参考

for k = 1:N
    e = r(k) - y;
    de = (e - e_prev) / Ts;
    e_int = e_int + e * Ts;
    e_int = max(min(e_int, 5), -5);
    u_pid = Kp * e + Ki * e_int + Kd * de;
    % u_pid = max(min(u_pid, 1), -1);
    train_e(k) = e;  train_de(k) = de;  train_u(k) = u_pid;
    u_delayed = u_buf(end);
    u_buf = [u_pid, u_buf(1:end-1)];
    x = Ad * x + Bd * u_delayed;
    y = Cd * x;
    y_pid(k) = y;
    e_prev = e;
end
这段代码在做什么

这是监督学习的数据采集环节。PID 在闭环中运行，脚本把每个采样时刻的 $(e,de)$ 与 PID 输出 $u$ 配对记录。这三列数据就是 ANFIS 要学习的"示范"。

关键参数与设计选择

  • Kp=0.8, Ki=0.05, Kd=0.5：对象直流增益 20，稳态控制量仅需 0.05；Kp=0.8 使初始误差 1 时比例项给出 0.8，Kd=0.5 在误差快速下降时产生强负向微分。这组参数响应偏保守、超调很小。好处是训练数据范围集中、数值稳定；代价是负误差样本很少——若系统几乎不超调，$e$ 很少变负，ANFIS 学不到"误差为负时减小控制量"的规则。
  • 执行器限幅被注释：PID 输出不受物理约束，能覆盖更大的 $u$ 范围，但真实执行器必有限幅。
  • e_int 限幅 ±5：防止积分饱和。
常见错误 ① 数据记录与对象更新顺序混淆：train_u(k) 记录的是当前时刻 PID 输出，这个输出经 u_buf 延迟后才影响对象。若记录写在对象更新之后，数据错位一步。
② de 用错差分方向：(e-e_prev)/Ts 是后向差分，当前时刻可算。
试一试把 Kp 从 0.8 调到 1.8，观察（a）PID 是否出现超调、train_e 最小值是否变负；（b）ANFIS 闭环性能是否改善。由此体会：训练数据中是否包含负误差样本，决定了 ANFIS 能否学会"刹车"。

步骤 3：训练/验证数据划分（对应模块三）

split_idx = floor(0.8 * N);
trnData = [train_e(1:split_idx), train_de(1:split_idx), train_u(1:split_idx)];
valData = [train_e(split_idx+1:end), train_de(split_idx+1:end), train_u(split_idx+1:end)];
这段代码在做什么

前 80% 时间（0~80 s）做训练，后 20%（80~100 s）做验证。anfis 用 valData 监控过拟合。

这份划分的局限（重要）

阶跃响应在 20~30 s 后基本进入稳态，所以后 20% 验证数据中 $e\approx0$、$de\approx0$、$u\approx u_{ss}$，几乎是常数。验证 RMSE 会非常低，但不能反映 ANFIS 在动态工况下的泛化能力。

想一想验证误差这么低，为什么 ANFIS 闭环性能不一定完美？

步骤 4：genfis 初始化与 anfis 训练（对应模块四）

genOpt = genfisOptions('GridPartition');
genOpt.NumMembershipFunctions = [3 3];
genOpt.InputMembershipFunctionType = 'gaussmf';
genOpt.OutputMembershipFunctionType = 'linear';
fis0 = genfis(trnData(:,1:2), trnData(:,3), genOpt);

anfisOpt = anfisOptions('InitialFIS', fis0, 'EpochNumber', 50, ...
                        'ValidationData', valData, 'DisplayANFISInformation', 1);
[fisTrained, trainError, stepSize, chkFIS, chkError] = anfis(trnData, anfisOpt);
这段代码在做什么

整个实验的核心模块，对应模糊神经网络两步。

第一步 genfis——搭骨架

用网格分割为两个输入各放 3 个高斯隶属函数，生成 $3\times3=9$ 条 Sugeno 规则。此时 fis0 的结构已确定，等价于五层前馈网络的拓扑；初始隶属函数中心和宽度由数据 min/max 均匀决定，后件线性系数由最小二乘初始化。genfis 不训练，它只决定"被训练的网络长什么样"。

第二步 anfis——训练

把 FIS 展开成五层网络，用混合学习算法——每个 epoch 先固定前件、用最小二乘一步求后件线性参数，再反向传播调整前件非线性参数。

关键参数

  • [3 3]：每输入 3 个隶属函数，9 条规则。规则数随输入数指数增长，是网格分割的固有代价。
  • 'gaussmf'：高斯型，两参数（中心、宽度），平滑可微，适合梯度下降。也可换 'gbellmf'，更灵活但更易过拟合。
  • 'linear'：Sugeno 一阶后件，每条规则结论是 $pe+q\,de+r$。
  • EpochNumber=50：9 条规则的小网络通常 20~30 个 epoch 收敛，50 留有余量。
  • chkFIS：验证误差最小处的 FIS 快照。若验证误差先降后升，chkFIS 比 fisTrained 更不易过拟合，建议对比两者的闭环性能。
常见错误 ① genfis 属性名写错：InputMFType 是错的，正确是 InputMembershipFunctionType。
② trnData 列顺序搞反：输入是前两列，输出是第三列。
③ 只看训练 RMSE 不看验证 RMSE。
试一试把 [3 3] 改成 [5 5]（25 条规则），观察训练 RMSE 和验证 RMSE 变化。训练误差通常更低，但验证误差可能抬头——这就是过拟合。由此体会：规则数不是越多越好，是在"表达能力"和"泛化能力"之间做权衡。

步骤 5：ANFIS 闭环仿真（对应模块五）——本实验最关键的模块

y_anfis = zeros(1, N);
x = [0; 0];  y = 0;
u_buf = zeros(1, delay_steps + 1);
e_prev = 0;

% 正弦参考信号
f_ref = 0.02;
r = sin(2*pi*f_ref*t);

for k = 1:N
    e = r(k) - y;
    de = (e - e_prev) / Ts;
    u_anfis = evalfis(fisTrained, [e, de]);
    % u_anfis = max(min(u_anfis, 1), -1);
    u_delayed = u_buf(end);
    u_buf = [u_anfis, u_buf(1:end-1)];
    x = Ad * x + Bd * u_delayed;
    y = Cd * x;
    y_anfis(k) = y;
    e_prev = e;
end
这段代码在做什么

结构与 PID 循环完全对称，唯一区别是控制律从 PID 公式换成 evalfis。这种对称性是刻意设计的：逐行对比两个循环，可以清楚看到"控制器替换"发生在哪一行。

三个必须注意的细节

  1. 状态全部重置：x=[0;0]、y=0、u_buf 重新初始化、e_prev=0。若忘记重置，ANFIS 仿真会从 PID 仿真的终点状态开始，结果完全错误。
  2. evalfis 输入顺序：新语法 evalfis(fis,[e,de])；R2018b 之前是 evalfis([e,de],fis)。报"参数过多"就是版本问题。
  3. 限幅被注释：ANFIS 输出不受约束，若某处输出很大值，对象会被"打飞"。
⚠️ 如果：训练用阶跃，测试用正弦

代码中 r=ones(1,N) 是阶跃，PID 数据生成（模块二）用阶跃参考；但模块五重新赋值 r=sin(2*pi*f_ref*t)，ANFIS 闭环仿真用正弦参考。

后果：ANFIS 学的是"阶跃跟踪时的 PID 行为"，却要去跟踪正弦。正弦跟踪的误差分布与阶跃完全不同（阶跃误差从 1 单调降到 0；正弦误差是围绕 0 的小幅振荡），ANFIS 很可能遇到输入超出训练范围，触发类似 Input 1 expects a value in range [...] 的警告，甚至闭环发散。

处理方式：

  1. 先按原代码运行，观察 ANFIS 正弦跟踪效果差、可能出现的警告。
  2. 自查："训练数据是什么工况？测试是什么工况？匹配吗？"
  3. 两条路径：
    路径 A（推荐，最简单）：模块五恢复 r=ones(1,N)，测试与训练同为阶跃。此时对比 PID vs ANFIS 的阶跃响应，结果干净可比。
    路径 B（进阶）：训练和测试都用正弦。把模块二的 r 也改成正弦（建议多幅值分段，扩大误差覆盖），重新生成数据再训练。
  4. 由此理解核心原则：训练工况必须覆盖测试工况。这是数据驱动控制与经典控制最本质的区别之一——PID 不需要"训练"，所以不怕工况变化；ANFIS 的性能上限由训练数据决定。
附带问题绘图时 plot(t,r,'k--') 用的是被覆盖后的正弦 r，而 y_pid 是阶跃响应，图中 PID 曲线与参考线对不上。这也是上述不一致的视觉表现，修复路径 A 后自动消失。

步骤 6：性能指标（对应模块六）

overshoot_pid = max(0, (max(y_pid) - 1) * 100);
settle_idx_pid = find(abs(y_pid - 1) > 0.02, 1, 'last') + 1;
ts_pid = t(min(settle_idx_pid, N));
ss_pid = mean(abs(y_pid(end-floor(0.1*N):end) - 1));
这段代码在做什么

三个经典阶跃指标。

  • 超调量：max(0,...) 保证无超调时返回 0。
  • 调节时间：find(...,1,'last') 找最后一次超出 2% 误差带的时刻，加 1 得首次进入并保持的时刻。min(...,N) 防止索引越界。
  • 稳态误差：取最后 10% 时间的平均绝对偏差。
局限与讨论点这套指标只对阶跃参考有意义。如果模块五用正弦测试，超调量和调节时间失去物理含义（正弦没有"稳态值 1"）——这正是建议模块五恢复阶跃测试的原因。另一个值得注意的点：ANFIS 没有积分记忆，稳态误差通常比 PID 大——这个差异本身就是"ANFIS 与 PID 结构性差异"的实证。
